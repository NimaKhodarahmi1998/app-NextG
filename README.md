The application was first named "GameChanger", but as I found out an application with this name already exists, I changed the name to "NextG".

NextG is a small application that help find the gamers to find a game to play next. This process happens as simply as shaking your phone and you will see the game to play next, alongisde its Genres, Metascore and everything else you need to know from a video game.

You do not like the game that appeared? Shake your phone again!
